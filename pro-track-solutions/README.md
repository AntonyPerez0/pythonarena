# Model solutions of the Pro Track

One folder per project of [`pro-track/`](../pro-track/), with only the `.py` files of the project's package that differ from its starter code. This repository's CI (`node scripts/pro-track-check.mjs`) copies them over the starter and requires every test to pass. The site never offers them for download: solve the project yourself first. See [`pro-track/README.md`](../pro-track/README.md).
